# SchellingBoard has moved

> [!IMPORTANT]
> **SchellingBoard now lives at [schellingboard/schellingboard](https://github.com/schellingboard/schellingboard).**
> This repository is an archived, read-only copy.

## Why

This repository was a fork of an older project, and GitHub treats forks as second-class:
they are hidden from search, and commits to them don't count on contributors' profiles.
The `LWCW-Europe` name also made SchellingBoard look like software for one event, when
it's meant for any conference. The new home is a standalone repository in its own
organization.

## What that means for you

- **Star the new repository**: stars couldn't be moved, so give it one if you like
  SchellingBoard.
- **Fork the new repository**: forks of this one are cut off from the project. To
  contribute, fork [schellingboard/schellingboard](https://github.com/schellingboard/schellingboard),
  or point an existing clone at it:
  `git remote set-url origin git@github.com:schellingboard/schellingboard.git`
- **Issues and pull requests keep their numbers**: #123 here is #123 there. Open issues
  moved over with their full discussion. Closed issues and pull requests stay here, and the
  new repository links to them.
- **Docker images** are still at
  [schellingboard/schellingboard](https://hub.docker.com/r/schellingboard/schellingboard) on
  Docker Hub, and the docs at [docs.schellingboard.org](https://docs.schellingboard.org).
